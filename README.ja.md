<p align="center">メディアの取り込みを、確認でき、追跡できるフローへ。</p>
<p align="center"><strong>フォトグラファー、映像制作者、個人クリエイター、制作チーム</strong>向けの、ローカルで動作するメディア取り込み・二重バックアップ・検証・プロジェクトアーカイブツールです。</p>

> [!IMPORTANT]
> 拾光は現在**無料ベータ版**です。重要な素材を扱う場合は元のメモリーカードを保管し、別の信頼できるバックアップが少なくとも1つ使用できることを確認してから、カードを初期化してください。ベータ版のみを重要な素材の保護手段にしないでください。

## v0.1.18 の更新内容

- プロジェクト一覧と詳細に読み込み・失敗・再試行の状態を表示します。低速ディスクへの問い合わせがタスク進捗の初期化を妨げず、再読み込みに失敗しても既存の一覧を保持します。
- プリセットの読み込み失敗時は元のファイルを保持し、保存成功後にメモリー上の値を更新します。変更のないプリセットは起動のたびに書き換えません。
- NAS アーカイブに永続タスク記録、元の計画の再検証、失敗後の新規タスク作成を追加しました。履歴を展開して、各試行のフォルダーを確認できます。
- MHL マニフェストの必須項目と特殊文字の処理を修正し、中断タスクの確認、補完コピーの表示、二重保存の結果説明を改善しました。
- 更新ダウンロードの停止時はタイムアウトします。無効になった更新パッケージは再確認でき、古い通知も取り下げられます。取り込み・アーカイブ中は引き続きインストールと再起動を禁止します。
- 小さなウィンドウでの詳細表示、レイアウト遷移、4言語のページ言語宣言を改善しました。

公開版 v0.1.16 → v0.1.18 について、この Mac の設定画面からダウンロード・インストール・自動再起動を確認しました。公開版 v0.1.17 は更新先が未設定のため、設定画面からは更新できません。タスクと拾光を終了し、この Release の DMG で旧版を置き換えてください。0.1.18 には更新先を設定済みです。プロジェクト記録・設定・カスタムプリセットは保持され、内蔵の動画プリセットには写真素材の保存先が追加されました。新しい Mac への初回インストールは未検証です。

## 拾光でできること

| 機能 | 説明 |
| --- | --- |
| メモリーカード検出 | 一般的な写真・動画・音声素材を識別し、撮影日、カメラ位置、プロジェクトプリセットに従って整理 |
| 安全な取り込み | 保存先の能力に合わせて安全な書き込み方式を選択。同名ファイルは上書きせず、異常終了時の残留は保存して明示 |
| 二重バックアップ | カメラカードを1回だけ読み取り、作業用ドライブと第2バックアップ先に同時書き込み |
| コピー検証 | 高速検証は可読性とサイズを確認。完全検証は保存先を再読み込みし、xxHash64 を元素材と比較 |
| レポートと重複防止 | MHL と人が読めるレポートを作成し、完了済みカードを記録。再取り込み時は新規または不足ファイルのみを処理 |
| プロジェクトとプリセット | 再利用できるフォルダーテンプレートで、原片、セレクト、完成品、音声、制作ファイルの構成を統一 |
| プロジェクトアーカイブ | 完全検証を実行し、プロジェクト記録とチェーン・オブ・カストディを保持。ローカル素材は自動削除しない |

## 検証方式

- **検証なし**：書き込み中のエラーの有無のみで判定します。最速ですが、重要な素材には適しません。
- **高速検証**：各ファイルの存在、可読性、バイト数の一致を確認し、欠落や明らかな切り詰めを検出します。
- **完全検証**：すべての保存先から全バイトを読み直し、xxHash64 を再計算してコピー時の元ハッシュと比較します。重要な撮影や二重バックアップに適します。

xxHash64 はコピー内容の一致を検出するためのもので、認証や暗号学的署名ではありません。検証後も重要な素材を実際に開いて抽出確認し、少なくとも2つのコピーが使用できることを確認してください。

## macOS での初回起動

v0.1.18 は Apple Developer ID で署名されておらず、Apple の公証も受けていません。そのため、macOS が初回起動をブロックする場合があります。

1. DMG は [Sorasukiawa/shiguang](https://github.com/Sorasukiawa/shiguang) の Releases からのみダウンロードしてください。
2. DMG を開き、「拾光」を「Applications / アプリケーション」フォルダーにドラッグします。
3. 通常どおり一度起動します。ブロックされたら警告を閉じます。
4. **システム設定 → プライバシーとセキュリティ**を開き、対象が「拾光」であることを確認して「そのまま開く」を選びます。

Gatekeeper を無効にする必要はありません。入手元が不明なパッケージのためにシステム保護を回避しないでください。

## ドライブの互換性

- **作業用、第2バックアップ用、アーカイブ先のドライブには APFS を推奨します。**
- **ExFAT も保存先にできますが、拾光の安全性チェックに合格する必要があります。**安全性を確認できない場合は素材を書き込む前に拒否し、上書きのおそれがある通常書き込みに切り替えません。
- **ExFAT のカメラカードは読み取り専用の素材元として直接使用できます。**

APFS と ExFAT では安全な書き込み方式が異なりますが、どちらも既存ファイルを上書きしません。拾光が元カードや既存の作業ドライブの初期化を求めることはありません。

## プライバシーとネットワーク

- 素材のスキャン、コピー、検証、プロジェクト記録はデフォルトでローカル処理されます。
- 拾光は写真や動画をアップロードしません。「拾光」のサーバーへ素材を送信することもありません。
- NAS やサードパーティの同期フォルダーを保存先にした場合、その後のネットワーク転送やクラウド同期は対応するシステムまたはサービスが行います。
- 自動更新チェックを有効にすると、公式更新元にアクセスします。更新を通知するだけで、取り込みやアーカイブの実行中に自動インストールしません。

## ベータ版の問題を報告する

[Issues](https://github.com/Sorasukiawa/shiguang/issues) に、拾光と macOS のバージョン、Mac のチップ、入力元と保存先のフォーマット、再現手順、エラー全文を記載してください。スクリーンショットには、顧客名、プロジェクト名、ローカルパスが写らないようにしてください。

Issue に元素材、顧客情報、非公開パス、その他の機密情報をアップロードしないでください。
